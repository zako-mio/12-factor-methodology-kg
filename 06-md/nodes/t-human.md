# 人为交互边界 (Human Interaction Boundary)

- ID: `t-human`
- 类型: 桥接主题
- 来源: 桥接
- 分组: GT09 · 人为交互边界
- 阶段: 高级 advanced

> 一次性管理任务 / 人类批准，皆是人机协作边界

## 核心主张 (what)

- 管理任务/人类批准，皆人机协作边界
- App 用 admin 进程执行运维
- Agent 把人类接入建模成工具调用

## 为什么 (why)

- 高赌注动作需人把关
- 人机协作不打断主路径

## 如何实践 (how)

- App 一次性进程同环境执行
- Agent 暂停循环等审批

## 三栏对比

| App 侧做法 | Agent 侧做法 | 差异根源 |
|---|---|---|
| admin 进程与常规同环境 | 联系人类=工具调用 | App 侧人是运维执行者 |
| 迁移/REPL 随应用发布 | 保存状态通知跳出循环 | Agent 侧人是自动决策节点 |
| admin 代码不分离 | webhook 恢复续跑 | 人从操作者变决策者 |
