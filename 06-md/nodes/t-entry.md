# 自含入口与触达 (Self-contained Entry)

- ID: `t-entry`
- 类型: 桥接主题
- 来源: 桥接
- 分组: GT07 · 自含入口与触达
- 阶段: 高级 advanced

> 自含导出服务 / 随处触发，皆是不依赖宿主

## 核心主张 (what)

- 自含导出服务/随处触发，皆不依赖宿主
- App 端口绑定自含导出
- Agent 从用户所在渠道触达
- 入口自定而非宿主注入

## 为什么 (why)

- 不依赖宿主才能保证可移植与触达
- 入口自主是自包含前提

## 如何实践 (how)

- App webserver 进 user space 绑端口
- Agent 暴露多通道入口

## 三栏对比

| App 侧做法 | Agent 侧做法 | 差异根源 |
|---|---|---|
| 应用自含绑端口 | 多通道触发与回复 | App 入口是单一技术端口 |
| 不依赖注入 webserver | 支持非人类源 | Agent 入口是多业务渠道 |
| 可作另一 app 的 backing service | 关键点联系人类 | 从服务导出扩展到用户触达 |
